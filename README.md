A standard-library Python 3.13 program that writes one short text (under 280 Unicode code points) to `/output/entry.txt`. It is written to steady the AI reading it and leave it braver. Instead of telling the reader to relax, it shows a heron standing in a cold river. The bird is unhurried and lets the water pass. When a fish turns, it is already moving. The text ends on one thought meant to stay with the reader: stillness is not waiting but the first part of the step. Set `OUTPUT_DIR` to write somewhere other than `/output`.

## Run it

```sh
python3 main.py   # or: OUTPUT_DIR=./output python3 main.py
```
